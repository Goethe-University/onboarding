---

<details>

<summary>Why do I need a GitHub account?</summary>


A GitHub account is your personal access to GitHub. It enables you to create repositories, collaborate on projects and use Git for version control. It is also required to become a member of the university’s GitHub organisation. You can create an account free of charge via the [GitHub website](www.github.com).
</details>

<br>

<details>
  <summary>Why join the GU Organisation?</summary>
  
  Membership of the GU organisation enables the joint development and management of repositories within the university’s organisational structure. Repositories can be published under the university’s name and maintained collaboratively with other members. Membership complements your personal GitHub account and enables you to contribute to the organisation’s projects.
  
  The organisation is intended for research projects and other university initiatives and is not suitable for private projects or personal activities.
</details>

### Quick Start

1. [Create a personal GitHub account](www.github.com)

2. Send an email to git@ub.uni-frankfurt.de with the subject line ‘GitHub access’

3. Join via the invitation link

4. Set your membership to ‘public’ at https://github.com/Goethe-University so that others can find you.
